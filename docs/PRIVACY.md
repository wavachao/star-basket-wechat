# 《接住小星星》隐私说明草稿

本文描述当前首版游戏代码的数据行为。正式发布前，实际运营者须补充真实主体名称、有效联系方式和生效日期，并与微信后台隐私保护指引配置核对。本草稿不包含虚构的运营主体或联系方式。

## 游戏保存什么

为显示本机最高分、记住音效选择，游戏使用微信本地存储；浏览器预览使用浏览器本地存储。保存的数据仅为最高分数字及音效开关，不包含姓名、身份证、手机号、微信头像、昵称或地理位置。

当前存储键为 `star-basket-v1:best`（数字）与 `star-basket-v1:sound`（布尔值）。游戏没有单独的清空存档按钮。

本局分数、生命、计时及物体位置存在游戏运行内存中，当前局结束或重新开始后重置，不上传到服务器。

## 数据传输与权限

本游戏代码没有自建服务器、登录、分析统计 SDK、广告 SDK、网络请求、云存档或好友排行榜，不将上述本地数据传给开发者。无需提供个人资料才能游玩，也不请求相册、通讯录、位置、摄像头或麦克风权限。

微信作为运行平台可能依据其自身协议和隐私政策处理平台服务数据；本说明只描述本小游戏代码行为。浏览器的存储和访问行为由所用浏览器管理。

## 保存期限与删除

最高分与音效选择保留在当前设备和应用的本地存储中，直至对应数据被清除。本地存档不跨设备同步；清理数据后无法恢复。

浏览器预览可通过浏览器的站点数据设置清除该站点本地数据。微信版本可使用微信客户端当前提供的小游戏数据或缓存管理方式；具体入口依客户端版本，操作前确认清除范围。开发者无法远程读取或删除用户设备上的存档。

## 联系与变更

实际运营者需在正式隐私说明中提供可联系的渠道，受理用户咨询。如未来加入广告、账号、排行榜、统计、服务器或其他数据处理功能，应先更新本说明与后台隐私配置，并按平台要求完成必要授权。

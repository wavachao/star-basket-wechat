## 重现

运行 npm run test、npm run check 和 npm run package。需要文档与截图资料包时运行 npm run package:archive；两种包均在解压后导入 wechat 子目录，内部续办记录不进入资料包。

可选浏览器验收使用 tests/browser-smoke.cjs，需要 Playwright 与 Chromium，并先启动 npm run preview。后续实际验收和后台进度应另行记录时间与结果。
